# Tachi-Proyecto

Este repositorio contiene una calculadora escrita completamente en Python. El
objetivo es disponer de funciones reutilizables para operaciones básicas y
algunas utilidades matemáticas sencillas.

## Características

- Suma, resta, multiplicación y división con validaciones de entrada.
- Cálculo del promedio para colecciones numéricas.
- Cálculo del factorial de números naturales.
- Verificación de números primos.

## Ejecutar las pruebas

```bash
pytest
```
